# Глоссарий

Термины, используемые в отчётах `docs/labN/README.md`. Раздел каждой лабораторной работы дополняется по мере её выполнения.

## LR2

| Термин | Определение |
| --- | --- |
| Amazon EC2 | Сервис виртуальных машин AWS; единица использования называется экземпляром (instance). |
| AMI | Образ, из которого запускается экземпляр: операционная система и предустановленное ПО. |
| Security Group | Виртуальный межсетевой экран на уровне сетевого интерфейса экземпляра; правила только разрешающие. |
| User data | Сценарий, который `cloud-init` выполняет при первом запуске экземпляра. |
| Key pair | Пара ключей: публичная часть хранится в AWS и кладётся на экземпляр, приватная остаётся у владельца. |
| nginx | Веб-сервер: принимает HTTP-запросы, сам отдаёт файлы, запросы к PHP передаёт в PHP-FPM. |
| PHP-FPM | Менеджер процессов PHP, выполняет скрипты по запросам nginx через unix-сокет. |
| Деплой | Доставка новой версии кода на работающий сервер; здесь выполняется скриптом `deploy.sh`. |
| ADR | Architecture Decision Record: краткая запись одного архитектурного решения. |

## LR3

| Термин | Определение |
| --- | --- |
| VPC | Изолированная виртуальная сеть в AWS с собственным диапазоном адресов (здесь `10.14.0.0/16`). |
| Подсеть | Часть адресного пространства VPC в одной зоне доступности; публичной её делает маршрут в Internet Gateway. |
| Internet Gateway | Компонент VPC, обеспечивающий двусторонний обмен между публичными адресами VPC и интернетом. |
| Таблица маршрутов | Набор правил "диапазон адресов -> цель"; всегда содержит локальный маршрут VPC. |
| NAT Gateway | Управляемый шлюз исходящего доступа: серверы приватной подсети выходят в интернет, входящих соединений нет. |
| Network ACL | Фильтр на границе подсети, правила разрешающие и запрещающие, применяются по возрастанию номера. |
| Bastion | Единственный сервер с SSH из интернета; на остальные серверы заходят через него (`ProxyJump`). |
| Elastic IP | Постоянный публичный IPv4-адрес, закрепляемый за ресурсом; оплачивается всегда. |
| Приватная зона Route 53 | DNS-зона, доступная только из выбранных VPC (здесь `timecapsule.internal`). |
| `pg_hba.conf` | Файл PostgreSQL, определяющий, кто, откуда и с каким способом проверки пароля подключается к каким базам. |
