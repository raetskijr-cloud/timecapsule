# Глоссарий

Термины, используемые в отчётах `docs/labN/README.md`. Раздел каждой лабораторной работы дополняется по мере её выполнения.

## LR2

| Термин | Определение |
| --- | --- |
| Amazon EC2 | Сервис виртуальных машин AWS; единица использования называется экземпляром (instance). |
| AMI | Образ, из которого запускается экземпляр: операционная система и предустановленное ПО. |
| Security Group | Виртуальный межсетевой экран на уровне сетевого интерфейса экземпляра; правила только разрешающие. |
| User data | Сценарий, который `cloud-init` выполняет при первом запуске экземпляра. |
| Key pair | Пара ключей: публичная часть хранится в AWS и кладётся на экземпляр, приватная остаётся у владельца. |
| nginx | Веб-сервер: принимает HTTP-запросы, сам отдаёт файлы, запросы к PHP передаёт в PHP-FPM. |
| PHP-FPM | Менеджер процессов PHP, выполняет скрипты по запросам nginx через unix-сокет. |
| Деплой | Доставка новой версии кода на работающий сервер; здесь выполняется скриптом `deploy.sh`. |
| ADR | Architecture Decision Record: краткая запись одного архитектурного решения. |
